HOW IT WORKS

Built around the WCAG formula

1

Linearize sRGB

For each normalized channel, use c / 12.92 when c ≤ 0.04045; otherwise use ((c + 0.055) / 1.055) ^ 2.4.

2

Calculate luminance

L = 0.2126R + 0.7152G + 0.0722B, using the linearized channels.

3

Calculate contrast

(lighter luminance + 0.05) / (darker luminance + 0.05). The result ranges from 1:1 to 21:1.
